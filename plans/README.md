## Corrections learned during execution

  line-start flag (otherwise the following text is indented mid-line). Step 3
  was wrong: `MagicString.indent()` never reads its own `indentExclusionRanges`,
  so `toMagicString()` dropping them has no effect; step 3.1 landed separately
  as #369.
- 008 part E: keep the `index < original.length` bound when copying
  sourcemap locations, or out-of-range locations leak into the next source.
- 009: vitest 5 moved `bench` onto the test context (`it(name, async ({ bench }) => bench.compare(...))`),
  tables only print with `--reporter=verbose` off-TTY, and it *does* support
  stored baselines (`writeResult`/`bench.from()`). The CI step needs `shell: bash` for `pipefail`.
- 011: `slice` throws for an anchor inside *any* edited chunk, removed ones included; default sequence count is 1000 (3000 took ~9 s).

## 2.0 decision list (recorded, not planned)

Each is a breaking change the audit surfaced; none is planned here because
the call belongs to the maintainer. Plan 004 fixes the legacy path in 1.x so
these can wait.

- Drop `insert()`, `insertLeft()`, `insertRight()` (deprecated 2016), the
  boolean 4th argument of `overwrite`/`update` (deprecated 2017) and the
  module-level `warned` flags; narrow `options` to the object types. Also lets
  `tests/MagicString/insert.test.ts` and `update.test.ts:121-154` drop their
  order-dependent `console.warn` tests.
- `MagicString.length()` excludes the string-level intro/outro (documented
  quirk) while `Bundle.length()` equals `toString().length`; align them.
- `snip()` carries "TODO deprecate this? not really very useful" since it was
  written.
- `Bundle.append(str)` adds a *source* (later `addSource` calls land after it),
  unlike `MagicString.append`; keep with the README caveat or rename.
- `hires: 'experimental-range'`: graduate (recommended hi-res mode, give it the
  streaming encoder) or isolate; it has had no follow-up since 1.3.0 and
  branches the hottest loop three ways. Needs plan 009's benchmark and a
  consumer-support check first. Related open defect: continuation lines of
  multi-line chunks get no segment in range mode (`'a\nbc'` → `b` unmapped;
  `tests/MagicString/generate-map.test.ts:530-537` carries a FIXME).

## Findings considered and rejected

- 53 TS2341 typecheck errors from `declare private` on `@internal` fields, and
  CI triggering only on `main` while the default branch is `master` — fixed
  upstream in #365 (`b28c233`).
- `update()`/`overwrite()` emptied chunks before throwing "across a split
  point" — fixed upstream in #364 (`f815ec4`).
- `snip()` ignored `offset` — fixed upstream in #363 (`bb5c6c2`).
- `replace`/`replaceAll` treating overwrite-emptied chunks as removed, and
  empty matches on a chunk boundary inside removed content — fixed upstream in
  #367 (`aed5675`) and #366 (`5aab3bd`).
- `slice()` returning `''` after `move()` when the end chunk precedes the
  start chunk in the output (incl. the no-argument call): a tested rule
  (`tests/MagicString/slice.test.ts:100-116`), not a bug; plan 007 documents it.
- `MappingsEncoder`'s module-level shared `scratch` buffer: sound — every
  `drain` ends with `flush()`, so nothing survives between calls even when
  `Bundle.generateMap` runs inside an `includeContent` callback.
- `getLocator` at/beyond `source.length`, lo-res BitSet word iteration
  boundaries (bits 31/32/63/64), `hasChanged()` after `move`/`reset`,
  `clone()` not copying `indentStr` (recomputed from the immutable original):
  checked, correct.
- `lastLine()`'s `substr` and `getBtoa`'s `unescape`: harmless Annex-B usage;
  `substr`→`slice` folded into plan 010, `unescape` left alone (replacement
  needs more code for no behaviour change).
- `ReplacementFunction`'s `...args: any[]`: mirrors lib.dom's
  `String.prototype.replace` typing; a precise union would be wrong for custom
  `Symbol.replace` implementations.
- `clone()` cost and `expandReplacement` per-match cost: proportional to the
  work; nothing to gain without a different data structure.
- `pnpm-workspace.yaml` release-age/trust policies and `update.ignoreDeps:
  typescript@7`: intentional; nothing blocks updates beyond a 24 h wait.
- `Bundle.generateMap`'s `as Omit<SourceMap, …> & {…}` cast and the
  `DecodedSourceMap`/`SourceMap`/`DecodedSourceMapOrMissingContent` triple:
  real debt, but redesigning the exported `SourceMap` shape is a public API
  change — listed for 2.0 rather than planned.
